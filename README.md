# uwr-cheatsheets

Zestaw skondensowanych notatek (ściąg) do przedmiotów wykładanych na Instytucie Informatyki.

Te notatki mogą być pomocne do powtarzania materiału, rozwiązywania list, przygotowań do kolokwiów/egzaminów.

Notatki są pisane w języku Typst a następnie kompilowane do dokumentów PDF.
